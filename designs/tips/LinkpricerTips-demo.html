📋 Integration Instructions

Step 1: Copy LinkpricerTips.jsx into your app's components folder.

Step 2: Import and place it at the root of your layout (before all other content):

// In App.jsx, _app.tsx, or your root layout file:
import LinkpricerTips from '@/components/LinkpricerTips';

export default function App() {
  return (
    <>
      <LinkpricerTips />
      {/* Rest of your app */}
      <YourMainNavigation />
      <YourPageContent />
    </>
  );
}

Step 3: Make sure your main app content has padding-top: 40px (or adjust for your banner height) so nothing gets hidden underneath.

Step 4 (Optional): Customize tips by passing the tips prop:

<LinkpricerTips 
  tips={[
    { text: "Your custom tip here", link: null },
    { text: "Clickable tip", link: "https://example.com" }
  ]}
  duration={45}
/>

✨ Features

  • Infinite scroll: Tips loop seamlessly from right to left
  • Pause on hover: Animation freezes when you hover over the banner
  • Clickable tips: Links open in new tabs with underline on hover
  • Dismissible: × button hides banner for the session
  • Accessible: Respects prefers-reduced-motion; allows horizontal scroll on reduced-motion devices
  • Responsive: Label collapses to icon on mobile; gaps adjust automatically
  • GPU-accelerated: Pure CSS animation, no JavaScript performance overhead

⚙️ Customization

Scroll duration: Pass duration={60} for a slower scroll (default is 45 seconds).

Tips content: Edit the tips array in the component or pass it as a prop. Only the "🍻" emoji is included in the default tips; keep other tips emoji-free for a clean look.

Colors: The banner uses your brand primary blue (#0052cc) and a light tinted background (#f0f7ff → #e6f2ff). Adjust the gradient and text color in the component's inline styles.
